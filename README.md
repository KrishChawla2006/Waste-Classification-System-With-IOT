# Waste-Classification-System-With-IOT
IOT project build using Arduino and ESP8266 NODEMCU

We have categorized waste into 3 categories:
1.Wet & Bio (Green Dustbin)

2.Dry Waste (Blue Dustbin) //Ultrasonic sensor on inner top of lid is used for measuring waste level.

3.Hazardous Waste (Black Dustbin)
